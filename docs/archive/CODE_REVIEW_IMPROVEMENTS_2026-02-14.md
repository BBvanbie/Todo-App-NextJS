# コードレビュー改善履歴（2026-02-14）

このドキュメントは、コードレビューで指摘された内容に対して実施した改善をまとめたものです。

## 実施済み改善

### 1. 期限日のタイムゾーン統一（JST）
- 対応内容:
  - タスク作成時の `dueAt` 保存を `JST 00:00` 基準に統一。
  - 一覧画面の期限判定（今日/7日以内/期限切れ）を東京タイムゾーン基準に統一。
- 主な変更箇所:
  - `app/tasks/new/page.tsx`
  - `app/page.tsx`
  - `app/_components/todos/model.ts`
- 効果:
  - 日付ずれや通知判定との不整合リスクを低減。

### 2. 削除失敗時のロールバック精度改善
- 対応内容:
  - 楽観的削除失敗時に「対象1件のみ」ではなく「削除前の配列全体」を復元するよう修正。
- 主な変更箇所:
  - `app/page.tsx`
- 効果:
  - 並び順崩れや表示不整合を防止。

### 3. アクセシビリティ改善
- 対応内容:
  - 完了/未完了トグルのタップ領域を 44px 以上に拡大。
  - トグルボタンに `aria-label` を付与。
  - `:focus-visible` のアウトラインを全体に追加。
- 主な変更箇所:
  - `app/page.tsx`
  - `app/globals.css`
- 効果:
  - キーボード操作性、タップ操作性、視認性を改善。

### 4. 認証の最小導入（Basic Auth）
- 対応内容:
  - `middleware.ts` を追加し、`BASIC_AUTH_USER / BASIC_AUTH_PASSWORD` が設定された場合のみ全体保護。
  - `CRON` ルートは既存運用を考慮して除外。
- 主な変更箇所:
  - `middleware.ts`
  - `.env.example`
  - `README.md`
- 効果:
  - 未認証でのアクセスリスクを即時に低減。

### 5. Cron エンドポイントの安全化
- 対応内容:
  - `POST /api/cron/notifications` を手動実行の正規ルートに変更。
  - `GET` は Vercel Cron リクエストと判断できる場合のみ許可。
  - `Cache-Control: no-store` を追加。
- 主な変更箇所:
  - `app/api/cron/notifications/route.ts`
  - `README.md`
- 効果:
  - 副作用のある `GET` の露出を縮小し、誤実行リスクを低減。

### 6. 画面構造の分割（保守性改善）
- 対応内容:
  - `app/page.tsx` の責務を分離し、モーダル/通知/一覧セクション/モデルをコンポーネント化。
  - `app/tasks/new/page.tsx` もフォームUIとモデルを分離。
  - 新規作成ページの文字化け文言を正常化。
- 主な追加ファイル:
  - `app/_components/todos/*`
  - `app/_components/new-task/*`
- 効果:
  - 可読性・再利用性・変更容易性を向上。

### 7. リポジトリ構成の一本化
- 対応内容:
  - 親リポジトリを正とし、重複していた `next-todos`（入れ子管理）を削除。
- 効果:
  - 運用の複雑さ（重複管理、同期ミス）を解消。

- 次段階として Auth.js（NextAuth）+ Prisma を導入し、ユーザー単位の認可に移行する。
